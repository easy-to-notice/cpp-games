# cpp-games

6 个 C++ 2D 小游戏合集，每个游戏是一个独立的 Visual Studio 解决方案（6 个 `.sln`）。

## 游戏列表

| 项目 | 类型 | 技术栈 |
|---|---|---|
| 1.提瓦特幸存者 | 2D 平面割草（生存） | EasyX |
| 2.植物明星大乱斗 | 2D 平面对战 | EasyX |
| 3.空洞武士 | 2D 平面动作 | EasyX |
| 4.哈基米大冒险 | 2D 联机打字竞速 | EasyX + cpp-httplib |
| 5.生化危鸡 | 2D 平面射击 | SDL2 |
| 6.拼好饭传奇 | 2D 平面经营 | SDL2 + C++17 |

## 构建说明

- **1–4 使用 EasyX，未随仓库附带**：需先安装 EasyX，并手工添加其 `include` 目录与链接 `EasyXa.lib`（工程文件中未预置这些配置，克隆后无法直接编译）。
- **5–6 自带 SDL2**（位于 `thirdparty/`），可直接构建，但**只能选 x64 配置**；5 号 `Debug|x64` 缺少 SDL 路径配置。
- **4 号**需分别构建并同时运行两端：服务端产物为 `server.exe`（目录名是 `serve`，工程名才是 `server`），监听 25565 端口，依赖 `serve\text.txt`；客户端依赖 `client\config.cfg` 中的服务器地址，需启动两个实例。
